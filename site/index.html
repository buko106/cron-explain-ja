    タイムゾーンの前提

    cron 式は UTC のサーバーで動くもの、日本語は Asia/Tokyo の時刻 として扱います。「日本語で書いた予定を UTC のサーバーの crontab に貼る」 「UTC の crontab を日本時間で読む」ための変換が入るため、上のふたつの欄では 時刻の数字がずれます。

    変換したくない場合はタイムゾーンに UTC を選んでください。 なお cron 式は「フィールドごとに独立した値の集合」しか表せないため、ずらした結果が その形に収まらない式（日をまたぐ時刻とまたがない時刻が混ざる、夏時間があるなど）は 近い式を返さずエラーにします。

    インストール

    npm i cron-explain-ja
    import { explain, parse } from "cron-explain-ja";

explain("0 0 * * 1-5"); // '平日の午前9時'   UTC 00:00 → JST 09:00
parse("毎日午後1時").expression; // '0 4 * * *'   JST 13:00 → UTC 04:00

    詳しい使い方は README を参照してください。
