曜日の範囲 `0-7` を全曜日として読む

`0 0 * * 0-7` は日曜だけでなく全曜日を指すが、`7` を先に `0` へ正規化していたため
`0-0`（日曜のみ）になっていた。`0-7` と `0-7/2` の展開値が cron-parser と食い違う。

```ts
explain("0 0 * * 0-7", { tz: "UTC" }); // 「毎週日曜日の午前0時」→「毎日午前0時」
next("0 0 * * 0-7/2");                 // 日曜のみ → 日・火・木・土
```

`1-7` のように始まりが `0` でない範囲は、`1-0` の循環範囲が同じ集合を指すため元から正しい。

あわせて cron-parser をベンチマークにした差分テストを追加した（`test/cron-parser-parity.test.ts`
と `test/cron-parser-cases.test.ts`）。展開値・次回実行日時・正規化表記の一致を、
フィクスチャとランダム生成の両方で突き合わせる。
