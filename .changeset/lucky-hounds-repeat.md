実在の crontab 201 件で `explain` の出力を人手で確認し（DESIGN.md §3.7）、
見つかった 3 件の不自然な出力を直した。

- 刻みの base がフィールドの全域を覆う場合、`*` と同じものとして畳むようにした。
  Quartz 由来の `0/5` は `0-59/5` に正規化されるため、
  `0 0/5 14 * * ?` が「午後2時台の0分から59分まで5分ごと」になっていた。
  時の範囲と重なると「午前8時から午前10時まで0分から59分まで30分ごと」のように
  「まで」が二重に出ていた。いずれも「5分ごと」「30分ごと」に短くなる。
  `*/1` も「1分ごと」ではなく「毎分」になる
- 時をリストで並べたときの「台」を各時に付けるようにした。
  `* 14,18 * * *` は「午後2時と午後6時台の毎分」となり「台」が午後2時に掛かっていなかった
- `@reboot` のエラーメッセージを、対応漏れではなく日時を持たないため説明できない旨に変えた。
  `crontab -l` をそのまま流し込むと必ず当たる

あわせて README に、曜日番号が Unix cron の 0 = 日曜であること
（Quartz は 1 = 日曜なので式をそのまま渡すと 1 つずれる）を明記した。
